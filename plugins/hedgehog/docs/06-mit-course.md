# MIT course behind the game: Topics in Mathematics with Applications in Finance

The Hedgehog Camp game's authors teach this MIT Mathematics course; StockTrak's Learning menu links its lectures and the 2024 course page announces the game. Materials are on MIT OpenCourseWare (CC BY-NC-SA 4.0). Use this map to point users to the right lecture or notes; link to OCW rather than reproducing material.
