Your Hedgehog Camp account, as an API

Let Claude, your scripts and other tools read your StockTrak game account and trade for you. One bookmark sets it up, and everything runs in your own StockTrak tab.

  • Works with Claude Desktop and Claude Code
  • REST and MCP

Connect Claude and other tools

your key is in the Hedgehog panel on StockTrak
  1. In the Hedgehog panel on StockTrak, open Claude Desktop and click Download.
  2. Double-click the downloaded Hedgehog.mcpb. Claude Desktop opens; click Install.
  3. Ask Claude something, for example “What's my buying power?”. Keep the StockTrak tab open.

No config files to edit. If you regenerate your key, download again: the new file installs over the old one.

  1. Copy your key from the Hedgehog panel.
  2. Run this once in a terminal, with your key in place of hgk_…:
claude mcp add --transport http hedgehog {{BASE}}/mcp/ \
  --header "Authorization: Bearer hgk_…"

Then start claude and ask about your account. Every order needs a trade_note; Claude writes one for you.

curl -H "Authorization: Bearer hgk_…" {{BASE}}/v1/account
import requests
H = {"Authorization": "Bearer hgk_…"}
order = {"symbol": "SPY", "side": "buy", "quantity": 10,
         "trade_note": "Rebalance into the index"}
print(requests.post("{{BASE}}/v1/orders", headers=H, json=order).json())

JSON in, JSON out. Errors always look like {"error": {"code", "message", "retryable"}}. Everything is in the API reference.

Cursor, Windsurf, VS Code and any other tool that connects to a remote MCP server with a header. Add this to its MCP settings:

{"mcpServers": {"hedgehog": {
  "url": "{{BASE}}/mcp/",
  "headers": {"Authorization": "Bearer hgk_…"}}}}

If your tool only runs local servers, wrap it: npx mcp-remote {{BASE}}/mcp/ --header "Authorization:Bearer hgk_…"

What you can call

send Authorization: Bearer hgk_… to {{BASE}}
CallWhat you get
GET /v1/statusIs your tab connected and logged in?
GET /v1/accountCash, buying power, value, trades remaining
GET /v1/positionsOpen positions
GET /v1/ordersOpen orders, or ?view=history with fills
POST /v1/ordersPlace an order (trade_note required)
POST /v1/orders/previewCheck an order without placing it
CallWhat you get
DELETE /v1/orders/{id}Cancel an open order
GET /v1/quotes/{symbol}Last price and quote
GET /v1/options/chainOption chain for a symbol
GET /v1/history/{report}Transactions, trade notes, closed positions
GET /v1/rewards/{section}H-Tokens: my_standing, my_week
MCP /mcp/The same, as 21 tools for Claude

If a call fails: tab_offline means the StockTrak tab is closed, session_expired means log in to StockTrak again, trading_disabled means trading is switched off in the panel. The full list is in the API reference.

Where is my key? The panel creates it and keeps it in your browser, on StockTrak. There is no account here. Regenerate in the panel replaces it everywhere at once.

Can it trade? Yes, by default. Switch “Allow trading” off in the panel for read-only. Every order still follows the game's rules.
