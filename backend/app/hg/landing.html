Your Hedgehog Camp account, as an API

Read and trade your StockTrak game account from Claude, scripts and any MCP or REST client. No sign-up: one bookmark creates your key, and every call runs in your own open StockTrak tab.

Exhibit 1
Each request runs in your StockTrak tab; nothing is stored about your account.

Note: Keep the tab open and logged in to StockTrak; with no tab, calls return tab_offline.

02

Connect Claude and other tools

your key is in the panel on StockTrak
  1. In the panel on StockTrak: Connect → Claude Desktop → ⬇ Download.
  2. Double-click Hedgehog.mcpb; Claude Desktop shows Install. Click it.
  3. Ask Claude, e.g. “What's my buying power?”. Keep the StockTrak tab open.

No JSON, no Node.js. New key after Regenerate? Download again: it installs over the old one.

  1. Copy your key from the panel.
  2. Run once in a terminal:
claude mcp add --transport http hedgehog {{BASE}}/mcp/ \
  --header "Authorization: Bearer hgk_…"

Then start claude and ask about your account. 21 Hedgehog tools; orders need a trade_note.

curl -H "Authorization: Bearer hgk_…" {{BASE}}/v1/account
import requests
H = {"Authorization": "Bearer hgk_…"}
requests.post("{{BASE}}/v1/orders", headers=H, json={
  "symbol": "SPY", "side": "buy", "quantity": 10,
  "trade_note": "Rebalance into the index"}).json()

JSON in, JSON out. Errors are always {"error": {"code", "message", "retryable"}}. Full reference: /docs.

Cursor, Windsurf and any client that supports remote MCP (Streamable HTTP) with headers:

{"mcpServers": {"hedgehog": {
  "url": "{{BASE}}/mcp/",
  "headers": {"Authorization": "Bearer hgk_…"}}}}

Clients that only run local servers: wrap it with npx mcp-remote {{BASE}}/mcp/ --header "Authorization: Bearer hgk_…".
